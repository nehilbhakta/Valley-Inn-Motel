# Valley Inn Downtown Phoenix website

A fast, mobile-first motel website built with **Next.js 15, React 19 and TypeScript**.
It exports to plain static files, so it can be hosted for free on GitHub Pages, Vercel or Netlify.

The site is built as a reusable template: every name, price, photo and phone number comes from
one file, `src/data/motel.ts`. To make a site for another motel, change that file and swap the photos.

## Features

- Hero photo slideshow (with pause button, and no auto-play for visitors who prefer less motion)
- Roadside-style rate sign with nightly prices and a call button
- Room cards with photo galleries, a full-screen photo viewer (keyboard and swipe support)
- Google Maps location and directions
- Booking form that emails a confirmation to the guest and a booking alert to the motel
  (EmailJS), with inline errors, a guest count that matches the room, and a spam trap
- Floating call button on phones
- SEO: page metadata, share previews (Open Graph) and Motel structured data (JSON-LD) for Google
- Optional Google Analytics with events for calls, form opens and booking requests
- Photos converted to WebP automatically (22.5 MB of originals become 4.4 MB)

## Run it on your computer

You need [Node.js](https://nodejs.org) 20 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:3000. Changes to `src/data/motel.ts` show up as soon as you save.

## Change the content

Edit `src/data/motel.ts`. Lines marked `TODO` still need the real details:

| Field | What to enter |
|---|---|
| `siteUrl` | The live address, e.g. `"https://valleyinnphx.com"` |
| `phone` | Display text and the number for the call link |
| `email` | Where guests can email the front desk |
| `address`, `geo`, `mapsUrl` | Street address, map coordinates and the short Google Maps link |
| `rooms[].price` | Nightly rate, e.g. `79.99`. `null` shows "Call for rate" |
| `analyticsId` | Google Analytics Measurement ID, e.g. `"G-AB12CD34EF"` |
| `emailjs` | EmailJS keys for the booking form (see `email-templates/README.md`) |

## Change the photos

1. Put the original photos (JPG or PNG) in the `photos` folder. The logo goes in `photos/logo.svg`.
2. Run `npm run images`. This creates WebP copies in `public/images`, the share preview image
   and the favicon, and records each photo's size in `src/data/images.json`.
3. Refer to photos in `motel.ts` by their file name in lowercase without the extension,
   e.g. `slide5.jpg` becomes `"slide5"`. TypeScript flags any name that doesn't exist.

## Booking form emails

The booking form sends a confirmation email to the guest and a booking alert to the motel through
EmailJS. Ready-made templates and step-by-step setup are in [`email-templates/`](email-templates/README.md).
Until the four EmailJS keys in `motel.ts` are filled in, the availability bar and reservation
form are still visible, but submitting shows a prepared request with an "Email this request"
(mailto) button and a call-to-confirm button instead of pretending an email was sent.
Once the keys are filled in, submitting emails the guest and the motel automatically.

## What's on the page

Hero slideshow with a "Rooms from $X/night" pill and call button, amenities strip, room cards
with prices, a navy "Book direct" strip, photo gallery with lightbox, welcome section with
check-in/check-out times, map and nearby places, a "Good to know" section, an FAQ, and a
book-direct band. Dates in the booking bar use the visitor's local date, not UTC, so
same-day bookings are not blocked after 5 PM Phoenix time.

## Publish

```bash
npm run build
```

This writes the finished site to the `out` folder.

**GitHub Pages (automatic):** push this project to GitHub, then go to Settings → Pages and set
Source to **GitHub Actions**. The workflow in `.github/workflows/deploy.yml` builds and publishes
the site on every push to `main`. For a custom domain, add it under Settings → Pages.

**Vercel:** import the GitHub repo at vercel.com. No settings are needed.

## Project structure

```
photos/                 original photos and logo (source files)
public/images/          optimized WebP photos (generated by npm run images)
scripts/                photo optimizer
src/app/                page layout, metadata and global styles
src/components/         one React component per section, each with its own CSS module
src/data/motel.ts       all of the motel's content
src/data/types.ts       the shape of that content
```
